TechHorizonXX Uploader: Privacy Policy

Last updated: 21 October 2026

What this tool is

TechHorizonXX Uploader is a private tool used by one person, the owner of the YouTube channel @TechHorizonXX. It is not offered to the public and no one else signs in to it. It uses the YouTube Data API v3 to upload the owner's own videos to that channel, set their titles, descriptions, tags and thumbnails, schedule their publish time, add them to a playlist, and post a first comment on the owner's own videos.

What data it accesses

Only the owner's own YouTube channel, through Google's OAuth sign-in, with the permissions to upload videos and to manage the owner's own comments. The tool does not collect, read or store any information about viewers, subscribers or other users.

What data it stores

The only credential stored is the owner's Google OAuth refresh token, kept as an encrypted secret in a private code repository. It is used only to upload to the owner's channel. It is not shared with anyone. The tool has no analytics, no advertising and no tracking.

Retention and deletion

The refresh token is kept only while the tool is in use. The owner can delete it at any time by deleting the secret in the private repository and revoking access at myaccount.google.com/permissions. Doing so removes the tool's access to the channel.

Sharing

We do not sell, share or disclose any data to third parties.

Google and YouTube

This tool uses YouTube API Services. By using YouTube you agree to the YouTube Terms of Service, and Google's use of data is described in the Google Privacy Policy. The owner can revoke the tool's access at any time at myaccount.google.com/permissions.

Contact

Questions can be sent through the About section of the TechHorizonXX channel.
